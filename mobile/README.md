# Mobile — Kalaswar Expo Application

This directory is reserved for the **Kalaswar Mobile Application** (built with Expo / React Native).

### Planned Capabilities
- **Artisan & Coordinator Dashboard**: Field-ready mobile interface for SHG Coordinators and Community Resource Persons (CRPs).
- **Offline-capable inventory tracking**: Village-level craft intake and stock counting.
- **Edge AI Quality Control (Phase 2)**: Camera inspection using lightweight computer vision (YOLOv8 / TFLite) to scan fabric weaves, dimensions, and stitching quality before dispatch.
